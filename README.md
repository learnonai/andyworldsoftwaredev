# Andyworld Software Development Website

A modern, responsive website for Andyworld Software Development company based in Pune, India.

## Features

- **Modern Design**: Clean, professional design with blue and white color scheme
- **Responsive Layout**: Optimized for all devices (desktop, tablet, mobile)
- **Fast Performance**: Built with Next.js for optimal loading speeds
- **SEO Optimized**: Meta tags and structured content for better search rankings

## Pages

- **Homepage**: Hero section, services overview, testimonials, and contact CTA
- **About Us**: Company mission, vision, team, values, and why choose us
- **Services**: Detailed service offerings with pricing tiers
- **Portfolio**: Project showcase, case studies, and technologies used
- **Contact**: Contact form, business information, and map integration

## Services Offered

- Web Development (React, Angular, Node.js)
- Mobile App Development (iOS, Android, React Native)
- Custom Software Solutions
- E-commerce Development
- UI/UX Design
- Digital Marketing Services

## Tech Stack

- **Framework**: Next.js 14
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Language**: TypeScript
- **Deployment**: Ready for Vercel, Netlify, or any hosting platform

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser
